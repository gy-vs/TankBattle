# 需求规格说明书

## 项目概述

**项目名称：** TankBattle - 坦克对战仿真环境  
**项目类型：** 多智能体对战仿真平台  
**技术栈：** Python + Flask + WebSocket + HTML5 Canvas  
**交付方式：** Docker 容器化，浏览器可视化访问

---

## 1. 业务场景

### 1.1 任务想定

- **红方**：某坦克排（3辆坦克）
- **蓝方**：某坦克排（3辆坦克）
- **战场**：14×14 平原地形网格地图
- **目标**：在规定时间内歼灭敌方

### 1.2 胜负判断

#### 胜利条件（满足任一）
1. 敌方坦克全部阵亡
2. 达到最大步长时，己方剩余坦克数 > 敌方坦克数
3. 达到最大步长时，坦克数相等但己方平均生命值 > 敌方平均生命值

#### 平局条件
- 达到最大步长时，坦克数相等且平均生命值相等

---

## 2. 核心实体

### 2.1 坦克 (Tank)

| 属性 | 初始值 | 最大值 | 说明 |
|------|--------|--------|------|
| health | 1000 | 1000 | 生命值，归零时坦克被击毁 |
| energy | 1000 | 1000 | 能量值，用于雷达和护盾 |
| missiles | 20 | 20 | 炮弹数 |

#### 伤害规则
| 攻击方向 | 伤害值 |
|----------|--------|
| 前方 | -200 HP |
| 侧方 | -300 HP |
| 后方 | -400 HP |

#### 资源消耗/恢复
| 场景 | 效果 |
|------|------|
| 维修厂 | 生命值 +150/步 |
| 能量补给站 | 能量 +250/步 |
| 雷达开启 | 能量 -探测距离×2/步 |
| 护盾开启 | 能量 -20/步 |
| 护盾被击中 | 能量 -200 |
| 发射炮弹 | 炮弹 -1 |
| 拾取弹药箱 | 炮弹 +7 |

#### 特殊规则
- 在维修站/能量补给站遭遇袭击，生命值直接归零（无论是否开护盾）
- 导弹速度 = 坦克速度 × 2
- 导弹之间不会爆炸，遇到坦克/障碍物才爆炸

### 2.2 地图元素

| 元素 | 符号 | 说明 |
|------|------|------|
| 空地 | open | 可通行 |
| 障碍物-树 | tree | 阻挡移动和雷达 |
| 障碍物-石头 | stone | 阻挡移动和雷达 |
| 维修厂 | health | 恢复生命值 |
| 能量补给站 | energy | 恢复能量 |
| 弹药箱 | ammo | 补充炮弹 |

## 3. 传感器系统

### 3.1 障碍传感器 (Blocked Sensor)
- **功能**：感知前/后/左/右相邻格是否被阻塞
- **限制**：无法区分障碍物和坦克
- **状态**：常开

```python
# 数据格式
blocked: {
    forward: "yes/no",
    backward: "yes/no",
    left: "yes/no",
    right: "yes/no"
}
```

### 3.1.5 视觉传感器 (Visual Sensor) ⭐新增
- **功能**：近距离识别周围的坦克
- **范围**：1-2 格
- **特性**：
  - 常开，不消耗能量
  - 可以区分敌方/友方坦克
  - 会被障碍物阻挡视线
- **用途**：即使雷达关闭（没有能量），坦克也能在近距离"看到"敌人

```python
# 数据格式
visual: [
    {distance: int, position: "forward/backward/left/right", color: "red/blue"},
    ...
]
```

### 3.2 导弹传感器 (Incoming Sensor)
- **功能**：感知任意距离来袭炮弹
- **限制**：
  - 被障碍物/其他坦克阻挡则无法感知
  - 敌方坦克距离≤2格发射的炮弹无法感知
- **状态**：常开

```python
# 数据格式
incoming: {
    forward: "yes/no",
    backward: "yes/no",
    left: "yes/no",
    right: "yes/no"
}
```

### 3.3 雷达 (Radar Sensor)
- **功能**：探测前方扇形区域（左/中/右3列）内所有物体
- **范围**：1-14 格（可设置）
- **消耗**：探测距离 × 2 能量/步
- **限制**：
  - 被障碍物阻挡
  - 无法被其他坦克阻挡
  - 敌方坦克在补给站时只能探测到补给站

```python
# 数据格式
radar: {
    energy: [{distance: int, position: "left/center/right"}, ...],
    health: [{distance: int, position: "left/center/right"}, ...],
    ammo: [{distance: int, position: "left/center/right"}, ...],
    tree: [{distance: int, position: "left/center/right"}, ...],
    stone: [{distance: int, position: "left/center/right"}, ...],
    open: [{distance: int, position: "left/center/right"}, ...],
    tank: [{distance: int, position: "left/center/right", color: "red/blue"}, ...]
}
```

### 3.4 雷达波传感器 (Rwave Sensor)
- **功能**：探测是否被其他坦克的雷达扫描
- **返回**：扫描方雷达所属阵营
- **状态**：常开

```python
# 数据格式
rwave: {
    forward: "red/blue/no",
    backward: "red/blue/no",
    left: "red/blue/no",
    right: "red/blue/no"
}
```

### 3.5 气味传感器 (Smell Sensor)
- **功能**：感知最近坦克的曼哈顿距离和阵营
- **范围**：最大28格
- **特性**：可穿透障碍物
- **状态**：常开

```python
# 数据格式
smell: {
    color: "red/blue",
    distance: int  # 1-28
}
```

### 3.6 声音传感器 (Sound Sensor)
- **功能**：感知最近的上一步移动的坦克方向
- **范围**：最大7格
- **返回**：最短路径方向
- **特性**：可穿透障碍物
- **状态**：常开

```python
# 数据格式
sound: "silent/left/right/forward/backward"
```

### 3.7 自身属性数据

| 属性 | 类型 | 范围 | 说明 |
|------|------|------|------|
| clock | int | 1-N | 全局时钟计数器 |
| direction | string | north/east/south/west | 坦克朝向 |
| energy | int | 0-1000 | 当前能量 |
| energyrecharger | string | yes/no | 是否在能量补给站 |
| health | int | 0-1000 | 当前生命值 |
| healthrecharger | string | yes/no | 是否在维修厂 |
| missiles | int | 0-N | 当前炮弹数 |
| my-color | string | red/blue | 坦克阵营 |
| radar-setting | int | 1-14 | 雷达设置距离 |
| radar-distance | dict | {left, center, right} | 雷达实际探测距离 |
| radar-status | string | on/off | 雷达状态 |
| shield-status | string | on/off | 护盾状态 |
| x | int | 1-14 | X坐标 |
| y | int | 1-14 | Y坐标 |
| ID | int | - | 坦克ID |

## 4. 动作系统

### 4.1 动作列表

| 动作 | 参数 | 说明 |
|------|------|------|
| AMove | forward/backward | 向前/后移动一格 |
| ATurn | left/right | 向左/右转向90° |
| ARadar | on/off | 开启/关闭雷达 |
| ARadarPowerSet | 1-13 | 设置雷达探测范围 |
| AShields | on/off | 开启/关闭护盾 |
| AFire | - | 向当前朝向发射一枚导弹 |

### 4.2 动作约束
- 每步只能执行一个移动/转向动作
- 雷达/护盾状态切换不占用行动
- 开火可与移动同时执行

## 6. 非功能需求

### 6.1 性能要求
- 单步仿真延迟 < 100ms
- 支持至少 1000 步仿真
- Web 渲染帧率 ≥ 30 FPS

### 6.2 可扩展性
- 支持自定义地图
- 支持自定义 AI 策略
- 支持调整仿真参数

### 6.3 部署要求
- Docker 容器化部署
- `docker compose up` 一键启动
- 通过 `localhost:端口` 访问
