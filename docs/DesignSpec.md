# TankBattle 视觉设计规范

## 设计理念

**主题风格：** 赛博朋克 × 军事科技  
**视觉关键词：** 霓虹光效、深邃暗色、高科技 HUD、粒子特效  
**用户体验：** 沉浸式战场、实时数据可视化、酷炫动态反馈

---

## 1. 色彩系统 (Color Palette)

### 1.1 主色调

| 名称 | 色值 | 用途 |
|------|------|------|
| 深空黑 | `#0a0e17` | 主背景色 |
| 战术灰 | `#131a29` | 卡片/面板背景 |
| 边界蓝 | `#1e3a5f` | 边框、分割线 |

### 1.2 霓虹强调色

| 名称 | 色值 | 用途 |
|------|------|------|
| 电光蓝 | `#00d4ff` | 蓝方主色、雷达、能量 |
| 烈焰红 | `#ff3366` | 红方主色、生命值、警告 |
| 脉冲绿 | `#00ff88` | 成功、激活状态 |
| 等离子紫 | `#bf5fff` | 弹药、特殊效果 |
| 能量橙 | `#ff9500` | 导弹、爆炸、高亮 |

### 1.3 渐变方案

```css
/* 电光蓝渐变 */
--gradient-blue: linear-gradient(135deg, #00d4ff 0%, #0099cc 100%);

/* 烈焰红渐变 */
--gradient-red: linear-gradient(135deg, #ff3366 0%, #cc0044 100%);

/* 霓虹边框 */
--glow-blue: 0 0 20px rgba(0, 212, 255, 0.5);
--glow-red: 0 0 20px rgba(255, 51, 102, 0.5);
```

## 3. 战场渲染 (Battlefield)

### 3.1 地图风格

- **背景：** 深色科技网格，带微弱脉冲动画
- **网格线：** 半透明蓝色，带发光效果
- **坐标系：** 显示网格坐标（可选）

### 3.2 地形元素

| 元素 | 视觉效果 |
|------|----------|
| 空地 | 暗色格子，带微弱纹理 |
| 树木 | 绿色发光圆形，带脉冲动画 |
| 石头 | 灰色多边形，带金属质感 |
| 维修厂 | 红色十字，带旋转光晕动画 |
| 能量站 | 蓝色闪电图标，带电弧动画 |
| 弹药箱 | 紫色弹药图标，带浮动动画 |

### 3.3 坦克设计

```
红方坦克：
- 主体：深红色金属质感
- 边缘：烈焰红霓虹发光
- 炮塔：带 ID 数字显示
- 状态：护盾时显示蓝色力场圆环

蓝方坦克：
- 主体：深蓝色金属质感
- 边缘：电光蓝霓虹发光
- 炮塔：带 ID 数字显示
- 状态：护盾时显示蓝色力场圆环
```

### 3.4 导弹效果

- **弹体：** 橙黄色三角形，带运动模糊
- **尾焰：** 橙红色渐变火焰
- **轨迹：** 半透明尾迹线

### 3.5 雷达可视化

- 扇形半透明区域
- 边缘带扫描线动画
- 探测到目标时高亮闪烁

### 3.6 爆炸特效

```
1. 白色闪光 → 膨胀
2. 橙色火球 → 向外扩散
3. 红色外圈 → 逐渐消散
4. 烟雾粒子 → 上升消失
```

## 4. UI 组件 (Components)

### 4.1 控制按钮

```css
/* 按钮基础样式 */
.btn {
  background: linear-gradient(180deg, #1e3a5f 0%, #0a1628 100%);
  border: 1px solid #00d4ff;
  color: #00d4ff;
  text-transform: uppercase;
  letter-spacing: 2px;
  box-shadow: 0 0 10px rgba(0, 212, 255, 0.3),
              inset 0 1px 0 rgba(255, 255, 255, 0.1);
}

/* 悬停效果 */
.btn:hover {
  background: linear-gradient(180deg, #00d4ff 0%, #0099cc 100%);
  color: #0a0e17;
  box-shadow: 0 0 30px rgba(0, 212, 255, 0.6);
}
```

## 5. 动效规范 (Animations)

### 5.1 核心动效

| 名称 | 时长 | 缓动 | 用途 |
|------|------|------|------|
| 淡入 | 300ms | ease-out | 面板显示 |
| 脉冲 | 1500ms | ease-in-out | 发光效果 |
| 扫描 | 2000ms | linear | 雷达动画 |
| 抖动 | 200ms | ease | 受击反馈 |
| 爆炸 | 500ms | ease-out | 击毁效果 |

### 5.2 关键帧定义

```css
/* 霓虹脉冲 */
@keyframes neon-pulse {
  0%, 100% { box-shadow: 0 0 10px var(--glow-color); }
  50% { box-shadow: 0 0 30px var(--glow-color), 0 0 60px var(--glow-color); }
}

/* 扫描线 */
@keyframes radar-scan {
  0% { transform: rotate(0deg); opacity: 0.8; }
  100% { transform: rotate(360deg); opacity: 0.8; }
}

/* 数据流动 */
@keyframes data-flow {
  0% { background-position: 0% 50%; }
  100% { background-position: 200% 50%; }
}

/* 受击抖动 */
@keyframes hit-shake {
  0%, 100% { transform: translateX(0); }
  25% { transform: translateX(-5px); }
  75% { transform: translateX(5px); }
}
```
